# Playbooks own task delivery; skills own capability methods

Playbooks sequence work and coordinate checks and delivery. Skills perform complete tasks and can be used directly: architect produces a design, diagnose fixes a bug, and verification generation creates and checks a verification skill. Shared acceptance procedures live with the skill, so playbooks can use them too. Callers reuse valid findings and evidence. When no playbook fits, `figure-it-out` designs one using the shared execution rules.
